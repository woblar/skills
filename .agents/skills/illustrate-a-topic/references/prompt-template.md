# Image prompt template

Build one prompt per requested image from the verified fact brief and chosen layout. Include only details the image tool needs.

- **Deliverable**. One standalone illustration of the topic for the stated audience, at the chosen aspect ratio.
- **Layout and scene**. The theme name, composition, objects, actions, visual relationships, and placement of labels and arrows.
- **Visible text**. The exact title, short captions, and takeaway. Keep research notes and citations outside the artwork by default.
- **Style**. Whiteboard marker linework, pastel fills, legible handwritten print, and generous whitespace.
- **References**. Identify which inspected inputs illustrate style or composition and describe them in the prompt when the tool cannot attach them.
- **Accuracy**. State the relevant physical or conceptual details and caveat. Exclude misleading additions such as an invented measurement, a false sequence, or incidental reference branding.

For a batch, keep the verified explanation consistent and change the scene plan to fit each composition.
